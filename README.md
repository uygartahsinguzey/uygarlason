# Berna V16.4 — Cozy Pixel Master UI

Bu sürümde Berna'nın tüm arayüzü daha güçlü bir cozy pixel tasarım diline geçirildi.

## Bu sürümde

- Tüm sekmeler için ortak cozy pixel tasarım sistemi
- Koyu ahşap + parşömen kart estetiği
- Daha oyunumsu ama yetişkin kullanıcıya hitap eden görünüm
- Dashboard benzeri Bugün sayfası
- Yeniden tasarlanmış Odak, Ajanda, Miki ve İlerleme ekranları
- GitHub Pages uyumlu HTML + CSS + JavaScript yapısı korunur

## Kurulum

ZIP içindeki dosyaları repository kök dizinine yükleyin. `index.html` doğrudan kökte kalmalıdır. GitHub Pages ayarlarında `main` ve `/(root)` seçin. Güncellemeden sonra sayfayı sert yenileyin.
